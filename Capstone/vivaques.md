A simple social network system using hashing for storing user profiles and a graph (adjacency list) for managing user connections.

Algorithms used
BFS (Breadth-First Search): used to find the shortest path (degrees of separation) between users
DFS (Depth-First Search): used to explore friends up to a certain depth
Hashing: used for efficient storage and retrieval of user profiles
Sorting: used to rank user recommendations based on common interests


This project implements a simplified social network using graphs and hashing. BFS is used for shortest path discovery, DFS for exploration, and hashing with sorting for user recommendations.
